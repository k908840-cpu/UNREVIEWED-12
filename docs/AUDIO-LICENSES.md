# Audio provenance and licensing

UNREVIEWED does not include downloaded music or sound-effect files. The
background loops and sound effects are original procedural Web Audio synthesis
implemented in `src/lib/sound.js`.

| Item | Source | Author | Licence / commercial use | Attribution |
| --- | --- | --- | --- | --- |
| Background music loops | N/A — generated from repository source code | UNREVIEWED project contributors | Original project work; it may be modified, redistributed, and included with the UNREVIEWED Android application under the project's distribution terms. | None required. |
| Sound effects | N/A — generated from repository source code | UNREVIEWED project contributors | Original project work; it may be modified, redistributed, and included with the UNREVIEWED Android application under the project's distribution terms. | None required. |

There are no third-party audio assets, licences, attribution notices, or
external audio URLs to carry into the Android release. Any future sampled track
must be added here with its direct source URL, author, licence text, and
attribution requirement before it is included in a release.
